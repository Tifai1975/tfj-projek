# Design Frontend — ORLOK Aceh Besar Landing Page

## Tujuan
Landing page publik ORLOK Aceh Besar (portal informasi & transaksi anggota ORARI Lokal Aceh Besar).

## Cara Pakai
1. Copy `landing-page.jsx` ke `frontend/src/app/page.js` (ganti yang lama).
2. Copy `globals.css` ke `frontend/src/app/globals.css`.
3. Copy `tailwind.config.js` ke `frontend/tailwind.config.js`.
4. Jalankan `npm run dev` di folder frontend.

## Struktur Halaman
- Hero: headline, subtext, CTA (Daftar / Login)
- Fitur: 3 kolom (Berita, Galeri, Transaksi)
- Statistik: anggota aktif, kegiatan, pengumuman
- Pengumuman & Kegiatan (dinamis dari API)
- Footer: kontak, copyright

## Brand
- Warna utama: Merah ORARI (#CC0000), Putih, Biru tua (#1E3A5F)
- Aksen: Kuning (#F5B800) untuk CTA
- Font: Inter (via Tailwind default)
