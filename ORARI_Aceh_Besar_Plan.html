Tech Stack

  • Frontend: Next.js 14 (App Router), TypeScript, Tailwind CSS, Shadcn/ui, React Hook Form + Zod, TanStack Query
  • Backend: Node.js + Express, Prisma ORM, JWT Auth, Bcrypt, Multer, Nodemailer
  • Database: SQLite (dev) → PostgreSQL 15+ (prod)
  • Payment: Manual bank transfer (member uploads receipt, admin approve/reject)
  • Email: SMTP (Gmail/SendGrid for password reset, bulk email)
  • DevOps: Docker Compose on self-hosted VPS, Nginx reverse proxy

Detailed Phases

Phase 1: Project Setup & Infrastructure

Files: Directory structure, .gitignore, README.md, backend/package.json, tsconfig.json, Prisma schema.

Initialize Express with TypeScript, Prisma with SQLite (dev), create 6 database models with full relationships.

Phase 2: Backend - Authentication

Files: src/utils/jwt.ts, src/utils/password.ts, src/middleware/auth.ts, src/routes/auth.ts

JWT access + refresh tokens, bcrypt password hashing, auth middleware with role-based authorization.

  • POST /api/auth/register
  • POST /api/auth/login
  • POST /api/auth/refresh
  • POST /api/auth/forgot-password
  • POST /api/auth/reset-password

Phase 3: Backend - Member Management

Files: src/routes/members.ts, src/utils/membership.ts

  • GET /api/members/me - current user profile
  • GET /api/members - admin list with pagination & search
  • GET /api/members/:id - view single member
  • PUT /api/members/:id - update profile (self or admin)
  • Membership expiry checker with 14-day grace period + auto-extend on payment

Phase 4: Backend - Transactions (Manual Transfer)

Files: src/middleware/upload.ts, src/routes/transactions.ts

  • POST /api/transactions - submit payment with receipt image (JPEG/PNG, max 5MB)
  • GET /api/transactions - list with filters (member/status)
  • PUT /api/transactions/:id/approve - admin approve + auto-extend membership
  • PUT /api/transactions/:id/reject - admin reject with reason

Phase 5: Backend - Activities, News, Frequencies

Files: src/routes/activities.ts, src/routes/news.ts, src/routes/frequencies.ts

  • Full CRUD for each module (admin create/update/delete)
  • Auto-generated slugs for news articles
  • Public read endpoints: GET /api/public/*

Phase 6: Backend - Admin Features

Files: src/routes/admin.ts, src/utils/email.ts

  • GET /api/admin/dashboard - summary stats (total/active members, pending payments, revenue)
  • GET /api/admin/reports/members - CSV export
  • GET /api/admin/reports/transactions - CSV export
  • POST /api/admin/email/bulk - send email to all active members

Phase 7: Frontend - Setup

Files: frontend/ (Next.js scaffold), src/lib/api.ts, src/lib/auth-context.tsx, src/lib/query-provider.tsx

  • Next.js 14 App Router with TypeScript
  • Shadcn/ui components (Button, Card, Table, Badge, Dialog, Tabs, Select, etc.)
  • TanStack Query + Axios API client with auto-refresh on 401
  • Auth context with login/logout + role-based state
